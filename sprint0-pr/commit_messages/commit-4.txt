Add create-task story: TaskService, form, list and create views (TM-F-010)

A signed-in user can create a task with title, description, due date and
priority (plus optional labels) and see it in the task list. A Project Manager
can also assign it to users; TaskService enforces the role rule, writes the
audit record in the same transaction, and queues a notification for the
assignee once the transaction commits.

Tests: TC-Task-01 (tests/task/test_tc_task_01.py) and form accessibility checks.
DEVIATIONS D-06 (assignees stored as assignment records) and D-07 (notification
stub not persisted) record where this differs from the SAD. docs/schema.md lists
the extra Task fields and Label.
