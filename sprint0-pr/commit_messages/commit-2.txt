Add Task, TaskAssignment and Label models with migration (S-04)

(TaskAssignment rows with assigned_by/assigned_at), status todo/in_progress/done,
soft delete via deleted_at, and a version counter for stale-edit checks
(SAD 4.4). Label has an archived flag (TM-F-051). Models are registered in the
Django admin and covered by ORM-level tests.
